# 色ツヤ工房

lilToon アバターの明るさ・色味・陰影・ツヤを、部位ごとに整える道具「色ツヤ工房」のオンラインマニュアルです。色ツヤ工房 0.6.0-preview.1 の画面に合わせています。プリセットの章は 1.1.0 の画面です。

## 手引書

- [オンラインで読む](https://creativeandcreative9.github.io/GP23_manual/)（公開準備中）
- [色ツヤ工房使用手引書.html](色ツヤ工房使用手引書.html)（HTMLファイル）

画像は `images` フォルダの中にあります。ダウンロードして読むときは、HTMLと同じ場所に置いたまま開きます。外部のフォントやスクリプトは必要ありません。

個人利用は無料です。作った物を売るときは商用ライセンスが必要です。
